## ✨ About

This is my personal portfolio website showcasing my journey in cybersecurity, featuring a terminal-inspired dark theme design. Built with modern web technologies, it highlights my skills, projects, certifications, and experience in the field.

---

## 🚀 Features

- **Terminal-Inspired Design**: Cyberpunk aesthetic with neon green accents
- **Responsive Layout**: Optimized for all devices
- **Smooth Animations**: Scroll-triggered fade-ins and skill progress bars
- **Dark Theme Only**: Focused on the cyber aesthetic
- **Fast Loading**: Optimized performance with vanilla JavaScript

---

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom properties, Grid, Flexbox, animations
- **Vanilla JavaScript** - Intersection Observer, DOM manipulation
- **No Dependencies** - Pure web technologies

---

## 📋 Sections

- **Hero** - Introduction with social links
- **About** - Personal background and stats
- **Skills** - Technical competencies
- **Experience** - Work history
- **Education** - Academic background
- **Certifications** - Professional credentials
- **Projects** - Featured work
- **Blog** - Latest posts
- **Contact** - Get in touch
